# 助手生成过程与流式呈现需求

## 背景

知识对话需要让用户知道助手正在检索、调用工具和组织答案，同时让回答在实际响应一次性返回时仍具有自然的渐进呈现效果。该需求适用于完整对话页、浮动面板、移动端抽屉和可继续访问的剪藏对话入口。

## 已确认决策

- 生成过程在生成期间可见。
- 生成完成后过程区域默认收起，但用户可以重新展开回看。
- 回答使用逐字符或逐词的浮现效果，以模拟流式输出。
- 过程展示必须与最终回答正文分离，不能把过程文本混入回答正文。

## 安全与产品边界

用户提出希望查看“完整思考文本”。产品不得直接展示模型的原始隐藏推理或 chain-of-thought，也不得把内部提示词、凭据、未脱敏工具参数或安全策略泄露给用户。可见过程应使用面向用户的简短思考摘要、阶段状态和工具调用摘要表达同等的可理解性。

可见摘要只能描述已经发生或正在发生的阶段，例如“正在检索站内文章”“已找到 3 个来源”“正在整理答案”。摘要不得声称未实际发生的检索、工具调用或阅读行为。

## 功能需求

### REQ-AGE-001 — 生成过程区域

- 生成中的助手消息 MUST 提供独立的“过程”区域。
- 过程区域 MUST 能表达思考摘要、站内检索、联网搜索、工具调用、结果整理和等待等阶段。
- 过程区域 MUST 使用可展开/收起的 disclosure 控件，并提供清晰的当前状态。
- 过程区域 MUST 与回答正文、来源列表和错误提示保持结构分离。

### REQ-AGE-002 — 过程内容边界

- 产品 MUST 展示经过筛选的用户可读摘要，不得展示原始隐藏推理全文。
- 工具步骤 MAY 展示工具名称、阶段、开始/结束状态、结果数量和面向用户的结果摘要。
- 工具步骤 MUST 隐藏凭据、完整提示词、内部系统指令、未脱敏参数、私人材料和不必要的原始响应。
- 无可展示细节时，界面 MUST 使用稳定的阶段状态，不得显示空白折叠面板。

### REQ-AGE-003 — 过程生命周期

- 生成期间过程区域默认展开，并随新阶段到达更新。
- 生成完成、主动停止或失败后，过程区域 MUST 默认收起，但仍可回看已记录的可见摘要。
- 关闭面板、导航、切换对话、刷新或短暂断线 MUST NOT 丢失已保存的生成状态，也不得重复执行同一提交。
- 恢复生成时，过程摘要和最终回答必须按服务端最新状态重建；过期的延迟事件不得覆盖终态。

### REQ-AGE-004 — 回答浮现

- 助手回答 MUST 支持逐字符或逐词的渐进浮现，即使服务端一次性返回完整内容，也 MUST 在展示层模拟自然的流式效果。
- 浮现 MUST 保持内容顺序，不得重复字符、跳字、改写正文或产生错误 Markdown 链接。
- 浮现期间已经出现的内容 SHOULD 保持稳定，避免因后续字符到达导致大范围重排。
- 用户主动滚动查看历史内容时，后续浮现不得强制把页面拉回底部；用户处于尾部跟随状态时才可继续跟随。

### REQ-AGE-005 — 控制与无障碍

- 用户 MUST 能停止生成，并能辨认停止是否由用户主动触发。
- 过程区域和回答区域 MUST 可用键盘操作，具有可访问名称、展开状态和焦点反馈。
- `prefers-reduced-motion: reduce` 开启时，界面 MUST 关闭字符/词级位移动效，保留即时可读内容和必要的状态变化。
- 浮现动画不得阻止复制、选择、阅读、来源访问或发送下一条消息。

### REQ-AGE-006 — 错误与降级

- 工具失败、搜索超时或摘要不可用时，界面 MUST 显示可理解的失败阶段，并继续展示已有回答内容。
- 过程摘要失败不得阻断最终回答；过程区域可降级为“过程信息暂不可用”。
- 不完整 Markdown 在浮现期间 MUST 保持可读，终态到达后使用服务端最终正文渲染。

## 验收标准

- 在站内检索、联网搜索、无工具回答、工具失败、主动停止、断线恢复和一次性终态响应场景中，都能看到独立的过程区域。
- 生成期间过程区域默认展开，终态后默认收起且可回看；切换页面或重新打开后状态与服务端一致。
- 一次性响应在视觉上按字符或词渐进出现，内容顺序正确，复制和 Markdown 渲染结果与最终正文一致。
- 减少动态模式下不出现逐字动画，但状态、正文、来源和错误仍完整可读。
- 桌面完整页面、浮动面板、393×852 移动抽屉和 320×800 窄屏均无横向溢出，折叠控件和停止操作可达。
- Web Demo 使用隔离 fixture 覆盖过程摘要、工具步骤、默认收起、失败、停止、恢复、逐字浮现和减少动态场景；live 构建不得因查询参数切换为 Demo。

## 待实现时确认的参数

- 逐字符或逐词的具体节奏、批量大小和最大动画时长。
- 过程摘要是否按消息保存完整可见事件，或仅保存终态摘要索引。
- 工具结果摘要的最大长度、来源链接展示方式和敏感字段脱敏规则。
