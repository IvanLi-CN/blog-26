## Verification Coverage

- VER-SKA-001–008 均未执行。需求文档的结构与链接检查不构成功能验证。
- 后续实现须使用可控时钟、确定性模型与检索 fixture 验证权限、配额、迁移和 usage 语义；真实提供方调用需要独立明确授权。
- 页面验收使用正式路由的独立 Web Demo，覆盖桌面与小屏及共享 Inspector，不新增页面级 Storybook 副本。
- 后续代码变更须运行仓库要求的检查与相关验证；重型验证按 Agent VM 合同执行。

## Remaining Gaps

- 尚需设计应用自有的前台身份衔接、私人对话持久化、生成恢复、计量接口与配额原子校验，并实现全部需求。
- 静态站运行时认证、Cookie/缓存隔离及动态前台必须一并验收，后台过期不能被错误地用作前台对话锁定条件。
- 旧讨论迁移需要可重复验证与恢复边界，不能直接删除不可信归属记录或猜测逐条作者；生产数据尚未读取或变更。
