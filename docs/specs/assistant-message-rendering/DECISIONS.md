## 源码事实与工程建议

当前用户消息也进入 Markdown、列表起始序号及脚注属性被丢弃、无语言代码按行内处理、全局清洗改变转义、引用编号与去重后来源记录无法稳定对应，均属于源码事实，不作为问题抛给用户决定。[证据矩阵](./CAPABILITY-MATRIX.md) 给出复核入口。

保留 react-markdown/unified、共享 Nature 控件和样式、扩展聊天专用策略、测量后决定优化、外图授权限定单消息确切 URL，以及组件接口布局，属于可逆的工程建议。它们在技术文档中给出依据，实施与验证完成前不宣称产品实现已完成。

没有为可逆的渲染库封装单独建立 ADR。ADR 0040 记录跨内容来源与资源请求的长期信任边界；引用编号将来若跨越服务端保存与历史兼容边界，再按真实取舍另建 ADR。

## 未纳入的扩展

定义列表、`==高亮==`、专门的 GitHub Alert 引用、emoji 短代码、任意上下标扩展、自动目录和 YAML 元数据不是本主题承诺的专门语法；合法 Unicode emoji 和标准 Markdown 仍正常显示。原始 HTML 的 kbd/sub/sup/table 不作为聊天专用扩展开放，代码围栏中的 HTML 保持代码。文件上传、附件管理、生成内容自动发布、来源编号数据库迁移与传输协议替换不在范围内。

范围外语法按标准解析结果或字面内容显示，不因产品未承诺专门样式而认定解析器故障。需要扩展时，先补充明确输入、显示、安全与降级合同。
