## Verification

相关测试包含聊天解析、代码与图片策略、消息状态、两个入口的 DOM 集成、有界展示状态、Web Demo 运行时与构建隔离，以及导入主线修复的 release source 测试。`bun run check` 通过，保留既有 warning/info；没有为消除提示而削弱检查。Storybook 构建与边界测试通过，页面证据继续使用正式路由 Web Demo。

`tests/e2e/web-demo/assistant-markdown.spec.ts` 使用 Inspector 的固定场景覆盖完整格式、AST 复制、实际浏览器图片请求、失败与停止反馈、增量快照、阅读位置和两个入口的生命周期。与 `assistant.spec.ts` 合并执行得到 49 项通过。1440px、800px、393px、320px 的浅深色场景验证表格、代码、公式局部溢出；不能用截图替代网络次数、生成提交次数或正文保持断言。既有助手的粗体与列表断言限定到消息正文并检验实际内容，避免来源列表造成严格多匹配，未移除原有权限和生成断言。

登出修复的受影响组件与策略测试分两组执行，共 98 项通过。真实退出 hook 的定向测试覆盖请求尚未完成、存储禁用和退出请求失败时的清理，最后 6 项、36 条断言通过；当前构建的 7 项浏览器回归覆盖键盘 Tab/Enter/Space、可见焦点、脚注实际回跳、正式评论退出、页面卸载与重载，以及原有导航和 Console 抽屉状态保持。

公开站展示元数据按身份与对话隔离、有界保存；只包含折叠选择及阅读位置，不保存正文或外图同意。真实退出入口按当前身份清除并撤销该文档中的展示命名空间，旧代码或滚动回调不能重建记录；其他身份和无关存储不受清理影响，新文档仍可正常记录。页面导航交接保留 Inspector 场景、主题、动效和网络延迟参数，live 产物仍不能由查询参数启用 Demo。阅读位置使用实际滚动宿主，异步资源完成与恢复尾部跟随均有独立断言。

Console 旧剪藏入口消费既有服务端 `status`、`errorCode`，不增加协议或存储字段。父组件持有有界内存展示状态及稳定消息身份，使移动端 Drawer 关闭、收到不同后端 ID 的保存终态、再次打开后仍保留主动折叠。静态回退不挂交互入口；受信任资源映射仅将同源 URL 规范为路径，不放宽任意 HTTP 图片策略。

资源门面的定向服务端测试 6 项通过、26 项断言，覆盖版本化资源与公开路由分发。受影响的既有 Console 剪藏用例在桌面、移动端均通过；不把其余未受影响的整套 Console 用例写为本候选已全部重跑。

## Remaining Gaps

本地受控验收通过不代表子 PR 审查、父 PR CI、主线合并、发布或部署通过。回归子 PR 与父 PR 仍需各自绑定实际 base/head 的证据；当前没有主线合并、release 或部署授权。

额外扩跑未修改的 `src/server/clipping/api.test.ts` 全文件曾出现两项快照导出超时及其后续失败；定向资源门面测试通过，但该扩展结果不能报告为全绿，也未为此修改无关后端。受控 Web Demo 使用模拟身份和固定数据，不证明真实模型输出或私人数据环境行为。

[能力审计矩阵](./CAPABILITY-MATRIX.md) 保留审计基线，不将其历史缺口当作当前结论。Mermaid、音视频和交互式嵌入仍不属于本期范围；正文裸编号到系统来源的编号映射也未扩入本期。
