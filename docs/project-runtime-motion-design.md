# 项目海报与运行数据面板切换动效

本文记录 `/projects` 开发工具分组中项目海报、项目运行数据面板与指标数值的动效设计。领域术语见 [GLOSSARY.md](../GLOSSARY.md)，现有视觉槽位与数据状态契约见 [Nature UI Spec](./specs/nature-front-ui/SPEC.md#project-visual-slot-geometry-and-density)。海报与面板切换、共享数值格式与滚轮控制器已接入产品；正式 Web Demo 浏览器回归与桌面、手机明暗主题的最终视觉验收已完成。

## 已确认方向

海报与项目运行数据面板切换采用分层递进。进入面板时，项目标识、指标与活动图依次淡入并轻微归位，使读者先识别项目，再读取数字与图表。主人已选择该方向。

多张卡片需要依次启动动画，允许各自的播放时间交叠，但不能同时开始。同一张卡片内部的分层递进与卡片之间的启动错峰共同构成两层节奏。

独立接口按实际就绪情况进入动画调度：已就绪的卡片先播放，慢卡片就绪后再接入，不等待整组接口返回。同批就绪的卡片按页面视觉顺序启动；先后就绪的卡片按就绪顺序启动。相邻卡片的启动时刻至少错开建议的 `140ms`，允许前一张仍在播放时启动后一张。只有一张卡片就绪且没有更早的启动占用该间隔时，可以立即播放。

示例沿用每层约 `320ms` 的时长、约 `6px` 的入场位移与层间 `50ms` 的启动间隔，单张卡片约 `420ms` 完成。卡片之间先采用 `140ms` 的启动间隔：三张卡片分别在 `0ms`、`140ms` 与 `280ms` 启动，在 `420ms`、`560ms` 与 `700ms` 完成。卡片启动间隔是可通过原型调整的建议参数。

## 现有行为

运行数据面板仅出现在项目列表中的 Codex Vibe Monitor、Tavily Hikari 和 OctoRill 卡片。首次请求等待时展示海报，有效响应使其切换为面板，HTTP、解析或协议校验失败使其回到海报，后续成功响应可以恢复面板。普通成功刷新只更新数据，不构成海报与面板之间的内容切换。

项目海报与面板共用固定 `4:5` 的项目视觉槽位。现有契约要求状态变化保持槽位与下方文字的位置稳定，排除高度动画，并尊重减少动态效果偏好。项目详情页保持海报展示。

## 可播放原型

动效样片采用现有项目海报、标识与装饰素材，并以固定示例指标重建面板内容。示例提供海报到面板、面板到海报、往返播放和三倍慢放。已选方向的示例默认让卡片依次启动，保留同时启动的版本供比较；卡片错峰对两个切换方向均生效。原型控件只用于演示，不构成新增用户切换入口的设计决定。

动效样片用于判断观感，不替代正式 Web Demo 的产品集成与浏览器验收。分层递进、卡片依次启动、按实际就绪情况调度与切换接续方式均已确认；生产组件已接入该动效，正式 Web Demo 已验证双向播放、改向接续、减少动态效果与手机横向浏览。

## 切换接续与交互边界

尚未开始的过时切换从等待队列中移除；已经播放的切换若遇到新目标，从当前可见进度接续到最新目标，避免完成旧动画后再补播新动画。普通成功刷新继续只更新指标，不重播入场动效。失败回退继续清理面板浮层与数据交互，保留项目详情导航。

## 指标数值格式与滚轮动效

以下要求适用于三张面板中的全部九项指标：Codex Vibe Monitor 的实时 Token/分钟、并行调用数和今日 Token 消耗量；Tavily Hikari 的今日请求次数、今日积分消耗量、本月积分消耗量和积分总量；OctoRill 的去重仓库数和压力值。日活动格 Tooltip 与指标共用数值格式，但 Tooltip 不播放数字滚轮。

带 `K`、`M`、`B` 或 `T` 后缀的数值四舍五入至最多两位小数，不强制补齐末尾的零。四舍五入达到 `1000` 时升级到下一个可用量级；不带量级后缀的普通数值保持现有精度规则，压力值保持固定两位小数。原始数值继续用于数据模型和计算，缩写只影响展示。

| 原始或缩写数值 | 显示示例 |
| --- | --- |
| `1.587K` | `1.59K` |
| `21.000K` | `21K` |
| `999.995K` | `1M` |
| 压力值 `4.53` | `4.53` |

面板首次显示时直接显示当前值，随面板入场，不从零虚构增长。面板已经显示后，只有新数据导致显示值变化时才播放数字滚轮；原始数值变化但显示值不变时保持静止。失败回退海报后的恢复视为首次显示，不从旧面板数值补播。

变化的数字列像计数器字轮一样滚动：上升时向上滚动并体现进位，下降时反向滚动并体现借位。数字与量级后缀在跨量级时同步切换到最终值，例如 `999.99K → 1M` 和 `1M → 999.99K`。一次变化约 `500ms`，平滑减速；跨度大时展示有限圈数，在相同时间内落到目标，不逐个播放所有经过的数字。播放中收到新值时从当前画面接续到最新目标，不排队补播过时值。

系统减少动态效果偏好生效时直接显示最终值。屏幕阅读器读取最终数值，不重复播报滚轮的中间数字。数值动效不推动卡片、图表或下方文案，桌面和移动端保持可读；窄空间沿用现有宽度适配与完整值提示。

验收应覆盖三张面板的指标和日活动格 Tooltip、不同量级及四舍五入边界、零和压力值、上升与下降、进位与借位、跨量级、大跨度、中途更新、显示值不变、首次显示、失败回退与恢复、减少动态效果、辅助技术读数，以及桌面和移动端布局稳定性。页面证据使用正式 `/projects` Web Demo，不新增页面级 Story 或独立产品演示路由。
