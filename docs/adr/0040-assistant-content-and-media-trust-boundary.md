# 助手内容与媒体请求的信任边界

助手回答采用受限 Markdown 展示，不取得文章作者可使用的原始 HTML 能力；模型输出中的脚本、iframe、事件属性和可执行 URL 不形成执行入口。系统认可的来源信息独立于正文保存和展示，正文中的编号或链接不能自行取得来源身份。

已获准的站内图片沿用现有资源访问边界；外部图片先显示链接或占位，由用户主动加载该图片。该选择接受自动呈现能力减少的代价，以避免阅读模型回答即向任意第三方资源发出请求；不能用同源代理、自动探测或后续预取绕过这个边界。

## Consequences

对话入口需要独立于文章渲染器的内容策略。共享代码、公式和图片组件时仍须保留聊天侧限制，文章已有受限 HTML 和媒体行为由原主题继续定义。实现与验收须同时检查最终 DOM 和资源请求，不能只以 HTML 已净化作为外部请求获准的证据。
