# 前台用户识别支持管理员账号与 GitHub 读者身份

静态站和动态站统一识别前台用户，身份可以来自已认证的管理员账号或 GitHub 读者登录。管理员自动拥有前台用户身份，无需绑定 GitHub，前台头像使用站点页脚的站长头像；已有管理员 GitHub 绑定仍可用于识别以该 GitHub 账号登录的管理员身份。

管理员前台身份享有不限助手对话数量、不自动过期及无 Token 额度限制的待遇，并可以在助手中检索非公开站内内容。服务端依据可信的身份来源识别资格，不按未经认证的邮箱、昵称或 GitHub login 猜测管理员身份。

同一管理员前台身份也用于公开评论和回复，无需绑定 GitHub 即可发表。服务端确认管理员身份后，新评论直接通过审核并保留管理员评论标记，公开作者头像使用站点页脚的站长头像。

前台助手依据自己的当前登录身份授权，不因后台登录过期而直接锁定前台对话；后台管理继续使用独立的管理员认证。剪藏讨论采用同一前台身份识别与对话能力，其统一模型见 [ADR 0037](./0037-unified-assistant-and-clipping-conversations.md)。

本决定扩展 [ADR 0031](./0031-github-admin-comment-identity-binding.md) 中绑定身份的用途，并取代其“管理员前台评论必须使用已绑定 GitHub 身份”的限制，保留显式身份绑定与后台权限隔离的边界；普通用户的对话保留规则见 [ADR 0032](./0032-temporary-assistant-conversations-and-usage-retention.md)。
