# 剪藏讨论属于统一的助手对话模型

剪藏讨论是站内对话功能中的一条助手对话，带有对应剪藏的阅读上下文。一般对话与剪藏关联对话共用对话模型、前台身份识别、入口、列表和界面；用户可从剪藏详情或全站对话界面继续同一条对话及其历史。

原有剪藏讨论的记录需要纳入统一对话能力，迁移必须保全既有消息和剪藏上下文，Memo 公开不表示对话记录公开。

旧剪藏讨论由创建者和管理员共用，未记录逐条消息的发言者。具有可信剪藏创建者的旧讨论整体归属该创建者，完整保留消息且不猜测逐条作者；无法确认归属的记录原样隔离保留，等待人工确认，不自动分配给其他前台用户。

每条对话归属于一个前台用户，同一篇剪藏下不同用户的对话分别创建并互不可见。统一列表只展示本人的一般对话与剪藏关联对话，普通用户的两类对话共用三个名额、七天保留期及个人配额；管理员不限额，但不自动读取其他用户的私人对话。

在剪藏详情页打开统一入口时，优先继续当前用户与该剪藏已有的对话；尚无对话则展示带剪藏上下文的草稿。首次发送消息才创建对话并占用名额，单纯打开面板不占用名额。面板已经打开时，页面导航不自动替换当前对话。
