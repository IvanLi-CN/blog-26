# 隔离 GitHub 读者身份与历史评论归属

> 本决定关于历史评论不按邮箱或昵称自动认领的边界继续有效；关于 GitHub 身份与管理员评论作者完全隔离的边界，已由 [ADR 0031](./0031-github-admin-comment-identity-binding.md) 取代。

原始决定将 GitHub 登录限定为读者公开评论和回复，并与博客唯一管理员的登录及授权分离；关于显式绑定后用于管理员评论作者识别的例外已由 ADR 0031 另行决定。读者新发评论和回复必须使用 GitHub 登录；历史评论保留内容、原作者署名与审核状态，由管理员继续管理，不按相同邮箱或昵称自动绑定 GitHub 账号，暂不提供读者认领。

既有游客入口在未验证邮箱所有权的情况下按自填邮箱复用用户并签发会话，历史数据也没有记录邮箱验证来源。因此，相同邮箱或昵称不足以证明历史评论与 GitHub 读者属于同一人；自动合并虽然方便旧作者继续编辑，但会把未经证明的身份关系转变成编辑、删除甚至管理权限。选择保持身份独立，接受旧作者暂时需要管理员协助处理历史评论的限制，避免在迁移后固化错误归属。

具体登录交互、评论覆盖范围及评论规则见 [GitHub 读者登录与公开评论 Spec](../specs/github-reader-comments/SPEC.md)，需求依据见[需求设计](../github-login-comments-design.md)；本决定不授权产品实现、历史数据迁移或删除。
