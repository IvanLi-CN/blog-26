# Public Mobile Content Stream

Status: accepted
Date: 2026-09-19

The public frontend keeps the chronological timeline as a desktop discovery pattern, but uses a 移动内容流 at widths below `640px`. The homepage and Memos preserve event order, dates, and content-type metadata while removing the decorative rail, nodes, and connectors; the homepage entry adopts the compact Memos item rhythm, with only the article/Memo type icon immediately before the date and no type text chip. Narrow public surfaces also flatten structural wrappers when their border, shadow, or nested card does not help scanning or interaction, while entity cards, media, and controls retain the framing needed to distinguish or operate them.

This separates information architecture from the desktop timeline treatment: the chronological path remains stable, while the mobile representation gives the reading column its full width and reduces visual and spatial overhead.
