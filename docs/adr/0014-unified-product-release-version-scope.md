# 统一产品发布单元

产品发布固定包含两种产物：静态前台和完整功能 Docker 镜像。两种产物共享同一个产品版本和同一次发布身份；镜像内的运行时、console 和 admin 是该镜像的组成部分。

产品版本与由提交生成的构建标识分别记录。发布身份绑定产品版本、确切来源提交、版本策略、有效预留，以及两种产物的校验值。

版本默认由系统按 Version Policy 自动递增，发版人可以可选指定更高的版本。系统根据可信的产品版本记录和有效预留验证单调性；低于基线的指定，以及试图为另一个发布身份复用相同版本的请求，都必须拒绝。失败恢复复用原发布身份和版本。

手动准备、受保护 PR 合并及实际发布边界由 [ADR 0015](./0015-manual-version-release-delivery.md) 定义。
