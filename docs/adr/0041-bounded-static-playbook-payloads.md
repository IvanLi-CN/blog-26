# ADR 0041：限制静态 Playbook 页面负载与发布体积

- Status: accepted

## 背景

公开包的原始 catalog/search 字节用于 digest 校验与原样恢复。将完整 edition 展开到页面 payload 会绕过正文裁剪，使所有 Playbook HTML 与路由 JSON 重复携带 base64 原始文件。本次内容产物达到 2,352,727,506 字节；EdgeOne 国内构建器复制到 `/dev/shm/repo` 时出现 2,102 条 `No space left on device`，仍错误地报告部署成功，导致空页面和空版本文件。

## 决定

页面投影只显式传递 edition identity、已裁剪 catalog 和空 documents 的 search 元数据；原始文件仅保留在完整性校验、缓存和公开 edition 资源中，不修改源字节、历史 edition 或搜索索引。

应用代码发布与内容更新在上传前共同执行 1 GiB 未压缩文件总量预算，并拒绝空首页、404、版本文件、配置文件、链接和特殊文件。预算是本站的保守发布门禁，不是平台公开存储限额，也不代表已测得平台临时文件系统的精确容量。诊断模式可以保留超预算产物，但不得发布或同步 supplement。

## 取舍

明确投影避免后续新增缓存字段再次进入浏览器。保守预算可能拒绝未来合法的大型站点；扩容应先取得平台容量证据，并重新验证完整页面、版本与配置，不能仅提高阈值消除失败。已经冻结的产品不改写，以新修复版本发布渲染器变更。
