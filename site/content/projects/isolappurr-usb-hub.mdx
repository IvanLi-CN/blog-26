## 数据隔离

IsolaPurr USB Hub 是一台面向桌面工作台的有源 USB 集线器和供电模块。
具备 2 kV 电气隔离的 USB HUB，支持 USB 2.0 480 Mbps，能有效保护主机安全。

非隔离域提供一个用于连接主机 USB-C 上行端口和一个用户连接其他设备的 USB-C 下行接口。

隔离域提供一个 USB A 型下行接口与一个 USB-C PD 下行接口。

## 电源隔离

非隔离域电源来自主机，下行接口电流能力受主机提供的能力限制，最大额定 5V/1.8A （可自己替换电阻调整）。

隔离域电源来自 DC5525 或 USB-C PD 输入，额定 9V-28V、1A-10A。
特别注意，为了确保电气隔离有效，必须使用独立的隔离电源作为隔离域的输入电源。
比如目前市售的手机、电脑的电源适配器，一般你能直接触碰的 AC-DC 电源是隔离的，不与主机共用同一路 DC 电源就行。

隔离域的电源用于主控和下行端口供电。如果希望 USB-C 接口提供 PD 电源能力，建议按至少 120% 的功率连接足额输入电源，并注意电流。

隔离域的 USB-C PD 电源还同时连接着一对 2mm 香蕉插座，支持提供 3V-21V、最高 5A 的可调电源输出能力。
支持 CC、CV 模式，电压步长 20mV、电流步长 50mA。

## 用户界面

硬件自带一个 1.47 英寸的彩屏，用于显示功率、状态等。左右两侧各有一个微动按钮，支持简单交互。

Isolapurr 主要依靠 Web App 进行交互，支持信息查看、接口数据与电源通断控制、PD 协议控制、可调电源功能设置、固件升级等。

附带 CLI 工具和 skills，方便接入 AI Agent 配合其他项目协同开发。

## 设备身份与连接路径

使用 ESP32-S3 作为主控制器，提供了 USB 和 WiFi 连接硬件的能力。

设备可以通过 Wi-Fi/LAN、Web Serial 或 Local USB 进入控制台。
Wi-Fi/LAN 适合日常局域网控制，Web Serial 适合浏览器直接连接，Local USB 由 `isolapurr-devd` 和 `isolapurr` 负责串口、代理、烧录和身份校验。三种路径对应不同的生命周期和使用环境。

## 硬件版本边界

仓库同时保留 `tps-sw` 和 `tps-fusb` 两个硬件方案。前者是当前正式版本，后者是下一版设计方向：它计划使用双 FUSB302B，并由 MCU 实现 USB-PD Fixed/PPS 的策略控制，但目前仍处于网表归档和验证前阶段。

当前版本正文只描述 `tps-sw` 的隔离、端口控制、设备身份和三种连接路径；`tps-fusb`、主动协议档位配置和未完成的实物验证仍属于后续工程。
